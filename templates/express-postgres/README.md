# Express + PostgreSQL Initly Template

A lightweight Express.js starter paired with PostgreSQL via the `pg` driver.
Generated by [Initly](https://github.com/anup2702/initly).

---

## Features

- **Express.js** server with a structured startup flow
- **PostgreSQL** connection helper and graceful shutdown handling
- **dotenv** driven configuration with `.env.example`
- **Nodemon** dev server for rapid feedback

---

## Getting Started

### 1. Scaffold the template

```sh
npx initly
# select express-postgres
```

### 2. Install dependencies

```sh
npm install
```

### 3. Configure environment variables

```sh
cp .env.example .env
# update the database credentials
```

### 4. Run database migrations (optional)

If you have SQL migrations, run them now using your preferred tool.

### 5. Start the server

```sh
npm run dev
```

The dev server boots on the port defined in `PORT` (default `3000`).

---

## Scripts

- `npm run dev` – start the server with nodemon
- `npm start` – start the server without file watching
- `npm run lint` – run basic lint checks with ESLint

---

## Environment Variables

The app reads configuration via `dotenv`. For convenience the template
supports both a single `DATABASE_URL` and discrete connection fields.

Required keys:

- `PORT` – HTTP port for Express
- `DATABASE_URL` *or* the individual `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`
